
# Comparative Study of ML Models for DT identification in LArTPC

Different ML Models and their comparison for analysing Dark Trident interactions in LArTPC.

# Authors
Rebecca Nasterlack

# Description

This repository is written in conjunction with the Masters Thesis "Comparative study of Machine Learning Models for signal identification in LArTPC" by Rebecca Nasterlack. This thesis is written for the Machine Learning and Big Data in the Physical Sciences MRes at Imperial College London.

The repository aims to supplement this report by providing a code based to facilitate simple reproduction of the study and encourage further research into this area.
